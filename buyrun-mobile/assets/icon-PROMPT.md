# Buyrun native icon

Generated with the built-in image_gen tool, followed by an image_gen correction to ensure an opaque background. Final export resized to 1024 × 1024 using macOS sips. Original template icon preserved in ../mobile-art/icon-backup/original-icon.png relative to the project directory.

Final assets: icon.png and adaptive-icon.png. Both are opaque square PNG files, with no rounded-corner mask.

## Original prompt

Use case: logo-brand
Asset type: Native mobile app icon for Buyrun.
Primary request: Create exactly one exceptionally clean, simple premium flat app icon. The entire square canvas is a solid lime color #DDFC79, edge to edge. In the center is a black lowercase bold letter "b", with pleasantly rounded geometric typography, and one tiny black four-point celebration sparkle at its upper right. Black means #101010.
Composition: Square 1:1 canvas, 1024 by 1024 pixels, flat full bleed color. The lowercase b and tiny star together must fit inside the central 60% of the image, balanced as one centered mark. The b should dominate; the star is small. Use crisp edges, superb spacing, app-icon legibility.
Style: Beautiful minimal flat vector-like symbol. No depth or texture.
Constraints: NO rounded outside corners: the background must fully fill all four corners of the square; the operating system will add its own mask. No border, outer frame, poster, mockup, shadow, gradient, lighting, texture, bevel or 3D. No text except the single lowercase "b". No wordmark, labels, extra elements or watermark.

## Final correction prompt

Edit this square logo icon. Keep the exact existing lowercase black b and small four-point star shape and the current overall centered arrangement. The current result incorrectly has transparency. Replace ALL transparent and greenish noise pixels with a completely opaque, perfectly flat pastel lime background color #DDFC79. Fill every pixel behind and inside the b, out to ALL four canvas edges and square corners with opaque #DDFC79. There must be ZERO transparent pixels. Treat this as a solid printed color tile. Black b and small black star, solid lime background. No corner mask. No shadow, gradient, added text or additional objects. Remove any residual speckles inside the letter counter so the interior is uniformly lime. Output exactly 1024x1024 if possible.
