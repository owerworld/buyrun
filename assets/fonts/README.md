# Link önizleme (Open Graph) yazı tipleri

Bu üç dosya sayfalarda ve WhatsApp/Telegram vb. için üretilen önizleme posterinde kullanılır.
Google Fonts'tan alınan Cormorant ve Manrope yazı tiplerinin, Türkçe karakterleri
(ç ğ ı İ ö ş ü) içerecek şekilde küçültülmüş (subset) hâlleridir. Lisans: SIL Open Font License 1.1.

Sayfalardaki fontlar next/font/local ile uygulamanın kendi adresinden yüklenir; tarayıcı Google Fonts’a istek göndermez.
