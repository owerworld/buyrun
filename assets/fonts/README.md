# Yazı tipleri

Google Fonts'tan alınan yazı tiplerinin, Türkçe karakterleri (ç ğ ı İ ö ş ü) içerecek şekilde
küçültülmüş (subset) hâlleri. Lisans: SIL Open Font License 1.1.

| Dosya | Nerede |
|---|---|
| cormorant-400/400i/500/600 | Başlıklar ve "Zarif", "Şiirsel" isim yazısı |
| manrope-400/500/700 | Arayüz metinleri |
| playfair-500/400i | "Görkemli" isim yazısı |
| greatvibes-400 | "El yazısı" isim yazısı |
| josefin-300/400 | "Modern" isim yazısı |

Sayfalardaki fontlar next/font/local ile uygulamanın kendi adresinden yüklenir; tarayıcı
Google Fonts'a istek göndermez. Davetiye yazı tipleri yalnızca onları kullanan sayfada indirilir.
Aynı dosyalar WhatsApp önizleme posterinde ve Instagram hikâyesi görselinde de kullanılır.
